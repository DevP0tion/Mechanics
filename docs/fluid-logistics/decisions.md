## 2. 결정 목록

결정마다 한 줄, 질문 주기 번호를 붙인다. 바뀐 결정은 지우지 않고 '대체됨' 표시 후 새 줄을 추가한다.

- 1-1. 핵심 부품은 파이프, 탱크, 펌프. — **대체됨 (3-1)**
- 1-2. 역할: 파이프 = 유체를 옮김, 탱크 = 유체를 담아둠, 펌프 = 유체를 끌어옴.
- 1-3. 탱크는 멀티블럭으로 구현하며, 조립형 가변 구조(여러 블록을 배치해 하나의 탱크로 인식)로 함.
- 1-4. 조립형 탱크의 구조 인식 규칙(이름·파라미터·동작)은 이번 세션에서 정의함 (세션 범위 확장).
- 2-1. 조립형 탱크의 구성 블록은 탱크 벽, 탱크 밸브, 탱크 컨트롤러, 유리 블럭.
- 2-2. 역할: 탱크 벽 = 탱크의 외곽을 이룸, 탱크 밸브 = 파이프가 연결되는 입출구, 탱크 컨트롤러 = 구조를 인식하고 상태를 보여줌, 유리 블럭 = 탱크 내부를 채움.
- 2-3. 탱크 밸브의 연결 대상은 파이프.
- 3-1. 요소 '탱크'의 이름을 '멀티블럭 탱크'로 바꿈. 조립된 탱크 구조(규칙 빈틈의 새 구성요소)의 이름도 멀티블럭 탱크. (1-1 대체: 핵심 부품은 파이프, 멀티블럭 탱크, 펌프)
- 3-2. 형태 조건: 탱크 벽이 직사각형 테두리를 이룰 때만 멀티블럭 탱크로 인식.
- 3-3. 내부 조건: 내부가 전부 유리 블럭이어야 함 (빈칸이 있으면 인식 안 됨).
- 3-4. 탱크 컨트롤러와 탱크 밸브는 벽 테두리의 한 칸에 놓임 (탱크 벽 자리를 대신함).
- 4-1. 최소 크기: 구조상 가능한 최소. (참고·계산값: 내부 1×1, 벽 포함 바깥 3×3)
- 4-2. 최대 크기: 내부(유리 블럭) 기준 5×5, 가로·세로에 각각 상한 적용. (참고·계산값: 벽 포함 바깥 최대 7×7)
- 4-3. 탱크 컨트롤러: 멀티블럭 탱크당 반드시 1개 (없으면 인식 안 됨, 2개 이상 불가).
- 4-4. 탱크 밸브: 개수 제한 없음, 하나도 없어도 멀티블럭 탱크로 인식됨.
- 4-5. 모서리 칸: 탱크 컨트롤러는 모서리 포함 테두리 어디든 가능, 탱크 밸브는 모서리 불가.

## 3. 미결 목록

태그: `[미정]`, `[문제]`, `[규칙 빈틈]`, `[확인]`, `note`

- `[미정]` 파이프/탱크 물류 방식의 세부 조정 (기획서 열린 항목)
- `note` D2: 커스텀 오브젝트 레이어의 렌더링·저장 자동 처리 여부는 구현 단계에서 검증
- `[규칙 빈틈]` 조립형 가변 탱크(1-3): 엔진 기본 기능이 아님(D3 MultiTile은 고정 크기만 지원). 구조 인식 규칙의 정의(이름·파라미터·동작)가 필요함. — 이번 세션에서 정의 진행 중 (결정 1-4). 정의됨: 이름·형태·내부·배치 위치·크기·개수·모서리 (3-1~3-4, 4-1~4-5). 남은 것: 동작
- `note` 멀티블럭 탱크가 리전 경계를 넘으면 일부 리전만 언로드될 수 있음(D5) — 구현 단계에서 검토.
