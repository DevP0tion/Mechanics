## 2. 결정 목록

결정마다 한 줄, 질문 주기 번호를 붙인다. 바뀐 결정은 지우지 않고 '대체됨' 표시 후 새 줄을 추가한다.

- 1-1. 핵심 부품은 파이프, 탱크, 펌프. — **대체됨 (3-1)**
- 1-2. 역할: 파이프 = 유체를 옮김, 탱크 = 유체를 담아둠, 펌프 = 유체를 끌어옴. — **일부 대체됨 (3-1: 이름 변경)**
- 1-3. 탱크는 멀티블럭으로 구현하며, 조립형 가변 구조(여러 블럭을 배치해 하나의 탱크로 인식)로 함. — **일부 대체됨 (3-1: 이름 변경)**
- 1-4. 조립형 탱크의 구조 인식 규칙(이름·파라미터·동작)은 이번 세션에서 정의함 (세션 범위 확장).
- 2-1. 조립형 탱크의 구성 블럭은 탱크 벽, 탱크 밸브, 탱크 컨트롤러, 유리 블럭. — **일부 대체됨 (5-7: 탱크 벽 삭제)**
- 2-2. 역할: 탱크 벽 = 탱크의 외곽을 이룸, 탱크 밸브 = 파이프가 연결되는 입출구, 탱크 컨트롤러 = 구조를 인식하고 상태를 보여줌, 유리 블럭 = 탱크 내부를 채움. — **일부 대체됨 (5-7: 탱크 벽 삭제)**
- 2-3. 탱크 밸브의 연결 대상은 파이프.
- 3-1. 요소 '탱크'의 이름을 '멀티블럭 탱크'로 바꿈. 조립된 탱크 구조(규칙 빈틈의 새 구성요소)의 이름도 멀티블럭 탱크. (1-1 대체: 핵심 부품은 파이프, 멀티블럭 탱크, 펌프)
- 3-2. 형태 조건: 탱크 벽이 직사각형 테두리를 이룰 때만 멀티블럭 탱크로 인식. — **대체됨 (5-13)**
- 3-3. 내부 조건: 내부가 전부 유리 블럭이어야 함 (빈칸이 있으면 인식 안 됨). — **대체됨 (5-5)**
- 3-4. 탱크 컨트롤러와 탱크 밸브는 벽 테두리의 한 칸에 놓임 (탱크 벽 자리를 대신함). — **대체됨 (5-13)**
- 4-1. 최소 크기: 구조상 가능한 최소. (참고·계산값: 내부 1×1, 벽 포함 바깥 3×3)
- 4-2. 최대 크기: 내부(유리 블럭) 기준 5×5, 가로·세로에 각각 상한 적용. (참고·계산값: 벽 포함 바깥 최대 7×7) — **일부 대체됨 (7-1: 기준을 내부 칸으로)**
- 4-3. 탱크 컨트롤러: 멀티블럭 탱크당 반드시 1개 (없으면 인식 안 됨, 2개 이상 불가).
- 4-4. 탱크 밸브: 개수 제한 없음, 하나도 없어도 멀티블럭 탱크로 인식됨.
- 4-5. 모서리 칸: 탱크 컨트롤러는 모서리 포함 테두리 어디든 가능, 탱크 밸브는 모서리 불가.
- 5-1. 인식 시점: 구성 블럭이 바뀔 때 자동으로 다시 확인함. 바닥 타일 변경도 포함.
- 5-2. 용량: 유리 블럭 수에 비례. — **대체됨 (5-8)**
- 5-3. 구조가 깨지면 저장된 유체는 소실. — **대체됨 (5-9)**
- 5-4. 상태 표시: 탱크 컨트롤러 UI 창 + 마우스 오버 툴팁(멀티블럭 탱크 내부에 마우스를 올렸을 때).
- 5-5. 내부 조건(3-3 대체): 다음 셋 중 하나 — ① 내부 전부 유리 블럭 ② 내부가 완전히 비어 있음 ③ 바닥 전부 탱크용 바닥타일(그 위에는 유리 블럭만 허용, 5-11).
- 5-6. 새 요소 '탱크용 바닥타일'(가칭, 이름 미정): 멀티블럭 탱크 내부 바닥을 채움. 특수 기능을 가진 타일로 만들 예정(기능 미정, TODO).
- 5-7. 요소 '탱크 벽' 삭제: 새 블럭을 만들지 않고 광물 벽으로 테두리를 만듦.
- 5-8. 용량: 테두리를 이루는 광물 벽의 최저 티어 + 내부 칸 수로 결정(조합 방식 미정). (5-2 대체)
- 5-9. 테두리 벽이 부서지면 멀티블럭 탱크는 비활성화만 되고 저장된 유체는 사라지지 않음. 유체 데이터는 탱크 컨트롤러에 저장. (5-3 대체)
- 5-10. 탱크 컨트롤러 자체를 부수면 저장된 유체는 소실.
- 5-11. 내부 조건 ③에서 바닥 위 오브젝트는 유리 블럭만 허용.
- 5-12. 광물 벽 = 나무·돌을 제외한 광물로 구성된 벽. 바닐라에 해당 벽이 없으므로 새 광물 벽을 모드에 추가(종류 미정).
- 5-13. 3-2·3-4의 '탱크 벽'을 '광물 벽'으로 바꿔 적용: 광물 벽(탱크 컨트롤러·탱크 밸브 포함)이 직사각형 테두리를 이룰 때 인식, 탱크 컨트롤러·탱크 밸브는 광물 벽 자리를 대신함.
- 6-1. 유체가 찬 모습 표현 방식: A(유리 블럭 반투명 레이어) + B(물 타일 텍스처 차용). 기존 물결 셰이더를 활용할 방법을 Claude가 조사함(조사 결과: domain-rules.md S3). — **대체됨 (6-7)**
- 6-2. 수위(양)는 텍스트로 확인: 탱크 컨트롤러로 확인하거나, 멀티블럭 탱크 내부에 커서를 올리면 커서 오른쪽에 `유체종류 현재 용량/전체용량` 형식으로 표기(대괄호 없음). (5-4의 툴팁 형식 구체화) — 형식 확인됨 (6-9: 유체 이름 현재값/최대값)
